# Interview Bot

## A Senior Design Project at CSULB

Interview Bot is an AI-powered interview preparation platform developed by **Phyyve**, a student team at California State University, Long Beach.

The platform is designed to help users practice job interviews in a realistic environment and receive meaningful feedback on their performance. Users can prepare for interviews using their resume and target job information, complete interactive interview sessions, and review feedback to identify areas for improvement.

---

## Features

- **Personalized Practice Interviews**: Generate interview experiences based on the user's resume, target role, and job information.
- **Text and Voice Interviews**: Practice responding to interview questions through multiple interview modes.
- **Contextual Interview Conversations**: Maintain interview context to generate relevant questions and follow-up questions.
- **Resume-Based Questions**: Use resume information to personalize interview questions.
- **Post-Interview Feedback**: Review feedback on interview responses, communication, and overall performance.
- **Speech Analysis**: Analyze speaking behaviors such as pacing, pauses, and filler-word usage.
- **Performance Tracking**: Review previous interview sessions and track progress over time.
- **Account Tiers and Access Control**: Control access to application features based on user account permissions.
- **User Dashboard**: Access interview history, progress, settings, and upcoming practice sessions from a centralized interface.

## Technologies Used

Interview Bot uses a modern full-stack architecture designed to support AI-powered interview practice and analysis.

### Frontend

- **Next.js**: Framework for building the Interview Bot web application.
- **React**: Component-based library for building interactive user interfaces.
- **TypeScript**: Provides type-safe application development.
- **Tailwind CSS**: Utility-first framework for application styling.
- **shadcn/ui**: Reusable UI components for the application.
- **Zustand**: Lightweight application state management.

### Backend

- **Next.js API Routes**: Backend API services supporting application features.
- **PostgreSQL**: Relational storage for application and user data.
- **Prisma**: Database ORM and schema management.

### AI and Interview Services

Interview Bot integrates AI and supporting services for:

- Interview question generation
- Contextual follow-up questions
- Resume-based personalization
- Speech-to-text processing
- Text-to-speech generation
- Interview feedback and analysis
- Knowledge retrieval for role and company context

Specific third-party services may change as the application is developed and evaluated.

### Development Tools

- **Git & GitHub**: Source control and team collaboration.
- **GitHub Projects**: Product backlog and sprint management.
- **GitHub Actions**: Automated CI checks for repository changes.
- **ESLint**: Automated code-quality checks.

## Development

Interview Bot is being developed using an Agile sprint process. Features are maintained as user stories in the team's GitHub Product Backlog and implemented through full-stack development across the frontend, backend, database, and supporting services.

Pull requests are reviewed before being merged into the `main` branch, and automated CI checks are used to verify application health during development.
